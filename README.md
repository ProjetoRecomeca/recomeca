# Recomeça

**"O caminho para uma nova história!"**

Plataforma web que promove a reintegração social e profissional de egressos do sistema prisional, oferecendo apoio educacional, emocional e tecnológico para a reconstrução de trajetórias e o acesso a novas oportunidades.

O Brasil investe mais em prisão do que em educação: menos de 13% dos presos estudam, e a reincidência real é de 32%, causada principalmente pela falta de oportunidade. O Recomeça atua nessa lacuna, usando educação e tecnologia para reduzir a reincidência.

---

## Funcionalidades

- Conteúdo educacional acessível para apoiar a qualificação dos usuários
- Canal de apoio emocional/psicológico
- Interface mobile first, com navegação simples e alto contraste (padrões WCAG)
- Conexão com rede de empresas parceiras para empregabilidade

---

## Pré-requisitos

Antes de começar, você vai precisar ter instalado:

- [Git](https://git-scm.com/)
- [Node.js](https://nodejs.org/) (versão 18 ou superior) e npm — *caso o projeto utilize dependências ou servidor local*
- Um navegador atualizado (Chrome, Firefox, Edge)
- Editor de código de sua preferência (recomendado: [VS Code](https://code.visualstudio.com/))

---

## Instalação

1. Clone o repositório:
   ```bash
   git clone https://github.com/seu-usuario/recomeca.git
   ```

2. Acesse a pasta do projeto:
   ```bash
   cd recomeca
   ```

3. Instale as dependências (se houver):
   ```bash
   npm install
   ```

4. Inicie o projeto localmente:
   ```bash
   npm start
   ```
   Ou, se o projeto for HTML/CSS/JS estático, basta abrir o arquivo `index.html` diretamente no navegador ou servir a pasta com uma extensão como o **Live Server** (VS Code).

---

## Como usar

1. Abra a aplicação no navegador (`http://localhost:3000` ou o endereço indicado no terminal).
2. Crie uma conta ou faça login como usuário.
3. Navegue pelas seções de conteúdo educacional, apoio emocional e oportunidades disponíveis.
4. Acompanhe seu progresso e acesse a rede de empresas parceiras.
